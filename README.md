# PranaFlow Yoga

A responsive static website for a yoga and wellness business, built for the CIA-2 Yoga Website Development Activity.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in your browser. For a local server, use VS Code Live Server or run `python -m http.server 8000` in this directory, then visit `http://localhost:8000`.

## Before publishing
1. Replace `hello@pranaflow.example` in `index.html` and `script.js` with an email address you control.
2. Update sample program prices and descriptions if needed.
3. Replace any sample contact details and sample content with real information.
4. Test the enrollment form. The current demo uses a `mailto:` link and does not store submissions. For reliable online submissions, configure a static form service such as Netlify Forms or Formspree.

## Deploy to GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, and this README.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the deployment to finish and open the published URL.

## Deploy to Netlify
1. Sign in to Netlify and choose **Add new site → Import an existing project**, or drag the project folder into Netlify Drop.
2. No build command is needed. Set the publish directory to the project root if asked.
3. Open the generated URL and test the site on desktop and mobile.

## Notes
- This is a student project concept. Prices and business content are illustrative.
- The page uses remote Unsplash images and Google Fonts, so an internet connection is needed for those assets.
- No payment processing or database is implemented.
